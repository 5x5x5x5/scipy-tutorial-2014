# Literate Programming

## Description

Literate programming combines code, its output, and explanatory text into a
single document. This makes research more transparent and easier to reproduce.

## Jupyter Notebooks

[JupyterLab](https://jupyterlab.readthedocs.io/) notebooks are the primary
literate programming tool in the Python ecosystem. Each notebook interleaves:

* **Markdown cells** - explanatory text, equations, images
* **Code cells** - executable Python code
* **Output cells** - results, plots, tables

Notebooks are stored as JSON files (`.ipynb`) and can be version-controlled
with Git.

## MkDocs for Documentation Sites

This tutorial's documentation site is built with
[MkDocs](https://www.mkdocs.org/) and the
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

MkDocs takes Markdown files and produces a static HTML website. The
configuration is in `mkdocs.yml`.

### Building the Site

```bash
# Build the static site
uv run mkdocs build

# Serve locally with live reload
uv run mkdocs serve
```

### Deploying to GitHub Pages

The repository includes a GitHub Actions workflow
(`.github/workflows/deploy-pages.yml`) that automatically builds and deploys
the site to GitHub Pages on every push to the main branch.

## The LaTeX Report

The `notebooks/analysis/sand-hopper.tex` file contains a LaTeX template for a
reproducible research article. It references code and results that can be
generated by running the analysis pipeline in `notebooks/analysis/00.py`.

To generate a PDF (requires a LaTeX installation):

```bash
cd notebooks/analysis
uv run python 00.py
pandoc sand-hopper.tex -o sand-hopper.pdf
```

## Hands On

1. Build the documentation site: `uv run mkdocs build`
2. Serve it locally: `uv run mkdocs serve` and open `http://localhost:8000`
3. Edit a Markdown file in `docs/` and see the live reload
