# Workflow

## Open Science Framework

The [Open Science Framework (OSF)](https://osf.io) is a free, open platform
for managing the entire research lifecycle.

### Create a Project

1. Sign up for a free account at [osf.io](https://osf.io/login/)
2. Create a project on OSF
3. Click on the contributors link and add a contributor
4. Edit the project's wiki to reflect the goals of the study

### Registration

Take a snapshot of the project before beginning data collection by going to the
registrations tab and clicking "Register project". Use the pre-data collection
registration template. This creates a frozen version of the project that can be
uniquely cited; it always contains a link back to the original project.

### Components

Components are organizational units within an OSF project. Use them when:

* Someone may be interested in a part of the project individually (to use or cite)
* Authorship is different for a given aspect of the project (e.g., analysis vs data collection)
* There are different authorization settings (e.g., certain data is public while other data is not)

### Integration with Other Services

OSF integrates with:

* **Figshare** - for data storage and sharing
* **GitHub** - for repository connection
* **Zenodo** - for archival and DOI assignment

### Exercise

1. Add a data component and connect it to your Figshare data
2. Add an analysis component and connect it to your GitHub repository
3. Make the project public
